# Ferns & Petals - Retail Operations Analysis

An Excel workbook that models customers, orders, products, and operations data, then presents them in an interactive dashboard.

## Overview

| Item | Detail |
|---|---|
| Customers | 100 |
| Orders | 1,000 |
| Products | 70 |
| Tooling | Excel, PivotTables, dashboard charts |
| Focus | Sales performance, product mix, customer profile, delivery operations |

## Workbook structure

| Sheet | Rows | Purpose |
|---|---:|---|
| `Customers` | 100 | Customer profile (anonymised for publication) |
| `Orders` | 1,000 | Order lines with dates, quantities, location, and occasion |
| `Products` | 70 | Product catalogue, category, price (INR), and occasion |
| `Ops_Data` | 34 | Operational reference data |
| `Source_Data_1` | 128 | Supporting analysis |
| `Source_Data_2` | 9 | Supporting analysis |
| `Dashboard` | - | Interactive dashboard |

## Analysis areas

- **Sales and orders** - order volume, revenue, and time-based trends.
- **Product performance** - best-selling products and category contribution.
- **Customer profile** - city and gender distribution, order frequency, and value.
- **Occasion analysis** - how demand changes across gifting and seasonal occasions.
- **Operations** - delivery timing and location-level view of fulfilment.

## How to open

1. Open `Ferns_and_Petals_Operations.xlsx` in Excel.
2. Go to the dashboard sheet.
3. Use the slicers and PivotTable filters to explore the data.

## Data notes

- The dataset is a representative retail operations sample prepared for this analysis.
- All customer contact details in the published workbook are placeholders; no real personal data is included.
- Prices are in Indian rupees (INR) as provided in the source data.
